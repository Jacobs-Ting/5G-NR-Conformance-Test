About Table 6.2.1-1

In the 5G NR (FR1) standard, UE Maximum Output Power is categorized into different Power Classes. Common classifications include:

  • PC3
    Class 3 (24 dBm) Default standard power, supported by the vast majority of 5G bands.
  • PC2
    Class 2 (26 dBm) High Power User Equipment (HPUE), often used for extended coverage (e.g., n41, n77).
  • PC1
    Class 1 (31 dBm) Ultra-high power for special applications (e.g., FWA CPE).
